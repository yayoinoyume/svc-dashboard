## 新增

- **检查更新**：设置页底部新增「关于」区块，显示当前安装的版本，可手动检查 GitHub Releases 上的最新版。
- 启动时静默检查一次（结果缓存 24 小时），有新版本时设置齿轮右上角显示小红点。
- 点「去下载」用系统浏览器打开 Release 页面，App 不申请存储权限、不调用系统安装器。
- 网络失败不会误报「已是最新」：上次已经知道的新版本会继续提示。

## 改进

- **实时流向按原名显示客户端**：`codex`、`acp-extension-codex`、`curl`、`Go-http-client` 等不再被吞进「其他」，magpie 上报什么就显示什么，同一个名字永远是同一个颜色。
- **客户端过多时折叠**：默认只画请求最多的 3 个，其余合并成「其他 N 种」（N 是实际剩余数量）。卡片右上角一个按钮切换展开 / 收起，展开后图表高度跟着增长，节点不再互相挤压。
- 合并项也有一条连到网关的线，粗细按剩余客户端的请求总量。
- 折叠时，没有任何可见入线的目标会暂时隐藏，避免图上出现孤零零的节点。

## 说明

- 已有的隐私统计（明细 → 隐私）保持原样，本次未改动。
- 从本版起，Release 页面上的更新说明来自仓库里的 `docs/releases/<版本>.md`，不再是一段固定文案。
- 安装：下载 `magpie-flutter-arm64.apk` 覆盖安装；老 32 位机型用 `magpie-flutter-armv7.apk`。首次打开需填写网关地址和访问密钥，密钥只保存在本机。
